Quantitative Analysis of Decision Quality in Competitive Chess

Overview
This project analyzes 200 rated chess games collected from Chess.com and Lichess engine analysis. Using Python, pandas, and custom statistical metrics, the project investigates relationships between decision quality, volatility, time management, and game outcomes.

Dataset
200 rated games
Thousands of move-level observations
Engine evaluations for every move
Time spent per move
Blunders, mistakes, and inaccuracies

Metrics
Volatility
Drawdown
Blunder Frequency
Time Pressure Correlation

Key Findings
Winning games averaged 0.30 blunders, compared to 1.34 for losses and 1.50 for draws.
Average thinking time showed almost no relationship with blunder frequency (correlation = 0.039).
Higher-volatility positions were associated with increased blunder frequency (correlation = 0.239).
